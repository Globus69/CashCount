# App-Icons

Euro-Münze im Theme-Look (teal Verlauf, weiße Münze, grünes €). Generiert mit
`/tmp/gen_icons.py` (Pillow). Zum Neu-Erzeugen/Anpassen das Skript erneut ausführen.

Vorhandene Dateien (vom Manifest & index.html referenziert):
- `icon-180.png` — Apple Touch Icon (180×180, full bleed; iOS rundet selbst)
- `icon-192.png` — 192×192, abgerundet ("any")
- `icon-512.png` — 512×512, abgerundet ("any")
- `icon-512-maskable.png` — 512×512, full bleed ("maskable")
